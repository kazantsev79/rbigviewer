# RBigViewer — просмотрщик больших текстовых файлов

Простой просмотрщик логов и других текстовых файлов любого размера (проверено на 10 ГБ / 101 млн строк).
Только чтение. Один исполняемый файл, ~5 МБ, без зависимостей.

## Что умеет

- Мгновенное открытие файла любого размера: в памяти держится не больше 64 МБ блоков на вкладку.
- Несколько файлов во вкладках: открытие через «Открыть…» (Ctrl+O), перетаскиванием в окно, из командной строки.
- Фоновая индексация строк: номера строк и общее число строк, переход к строке (Ctrl+G).
- Автоопределение кодировки (BOM → UTF-16 → UTF-8 → chardetng) и ручное переключение в строке состояния.
- Очень длинные строки (например, однострочный JSON на сотни МБ) режутся на экранные куски по 16 КБ (в колонке номеров стоит `↪`).
- Режим «Следить за концом» (как `tail -f`); дописывание файла и ротация (уменьшение размера) отслеживаются.
- Файл открывается с разрешением другим программам писать, переименовывать и удалять его.

## Клавиши

| Клавиша | Действие |
|---|---|
| Ctrl+O | Открыть файл(ы) |
| Ctrl+W / средняя кнопка на вкладке | Закрыть вкладку |
| Ctrl+Tab | Следующая вкладка |
| Ctrl+G | Перейти к строке |
| ↑ ↓ PgUp PgDn, колесо | Прокрутка |
| ← → , Shift+колесо, Home | Горизонтальная прокрутка |
| Ctrl+Home / Ctrl+End | Начало / конец файла |

## Сборка

```bash
cargo build --release
```

Windows (нативно): тот же `cargo build --release`, результат — `target/release/rbigviewer.exe`.

Кросс-сборка под Windows из Linux:

```bash
rustup target add x86_64-pc-windows-gnu
sudo apt-get install gcc-mingw-w64-x86-64
cargo build --release --target x86_64-pc-windows-gnu
```

## Устройство

- `source.rs` — чтение блоками по 1 МБ с LRU-кэшем и фоновым потоком; интерфейс никогда не ждёт диск.
  Очередь запросов обрабатывается с конца (самый свежий запрос первым) и ограничена 16 элементами.
- `index.rs` — разреженный индекс: число переводов строк до начала каждого блока (~10 000 чисел на 10 ГБ).
- `encoding.rs` — определение кодировки и поиск переводов строк (`0A`, `0A 00`, `00 0A`).
- `doc.rs` — навигация: позиция просмотра — смещение верхней строки в байтах; операции, которым
  не хватило данных, повторяются в следующем кадре.
- `main.rs` — интерфейс на egui/eframe (рендер через OpenGL).
